💡The big insight

Project knowledge is shared — documents, scripts, references. Only the files in configuration change names and formats. Anyone who understands this map can migrate between runtimes in minutes, not days.

Who this course is for

✓ It’s for you if…

  • ✓You already use Claude Code (or Codex) and want to learn the other without having to relearn everything
  • ✓You want to run both agents in the same project without duplicating content
  • ✓Creates skills/sub-agents and gets tired of maintaining two versions by hand
  • ✓You want to be tool-agnostic and stop depending on just one ecosystem

✗ It’s not for you if…

  • ✗Look for an introductory tutorial on “what is an LLM”
  • ✗You want a model comparison (GPT vs Claude). This is about runtime, not models.
  • ✗Expect the course to decide for you which tool is "better"

Ready to get started?

If you’ve never seen either one, start with Track 1. If you’re already fluent in both, go straight to Track 5 (polyskill) — that's the key trick.
