💡La gran idea

El conocimiento del proyecto es compartido — documentos, scripts, referencias. Solo los archivos de configuración cambian de nombre y formato. Quien entiende este mapa migra entre runtimes en minutos, no en días.

Para quién es este curso

✓ Es para ti si…

  • ✓Ya usas Claude Code (o Codex) y quieres aprender el otro sin tener que reaprender todo
  • ✓Quieres ejecutar ambos agentes en el mismo proyecto sin duplicar contenido
  • ✓Crea skills/sub-agents y se cansa de mantener dos versiones a mano
  • ✓Quieres dejar de depender de un solo ecosistema y no atarte a una herramienta

✗ No es para ti si…

  • ✗Busca un tutorial introductorio sobre "qué es un LLM"
  • ✗Quieres una comparación de modelos (GPT vs Claude). Aquí se habla del runtime, no del modelo.
  • ✗Esperas que el curso decida por ti qué herramienta es «mejor»
