💡A grande sacada

Conhecimento do projeto é compartilhado — documentos, scripts, referências. Só os arquivos de configuraçêo mudam de nome e formato. Quem entende esse mapa migra entre runtimes em minutos, nêo em dias.

Pra quem é este curso

✓ É pra você se…

  • ✓Já usa Claude Code (ou Codex) e quer aprender o outro sem reaprender tudo
  • ✓Quer rodar os dois agentes no mesmo projeto sem duplicar conteúdo
  • ✓Cria skills/sub-agents e cansa de manter duas versões à mêo
  • ✓Quer ficar tool-agnostic e parar de depender de um ecossistema só

✗ Nêo é pra você se…

  • ✗Procura tutorial introdutório de "o que é um LLM"
  • ✗Quer comparativo de modelo (GPT vs Claude). Aqui é sobre runtime, nêo modelo.
  • ✗Espera que o curso decida por você qual ferramenta é "melhor"
